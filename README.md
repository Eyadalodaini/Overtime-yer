# إضافي | Overtime YER — الإصدار 1.1.0

تطبيق Flutter عربي RTL لحساب ساعات العمل الإضافية بالريال اليمني، يعمل محليًا دون إنترنت.

## أهم الإصلاحات

تمت مراجعة الكود وإصلاح أخطاء كانت تمنع البناء أو تجعل بعض الوظائف لا تعمل بشكل صحيح:

1. إصلاح `await await` في `main()`.
2. إضافة `OvertimeApp` الذي كان مفقودًا رغم استخدامه في `runApp()`.
3. إصلاح استدعاءات `NotificationService.schedule()` التي كانت تستدعى بدون المعاملات المطلوبة.
4. إصلاح جدولة التذكيرات: حلقة الأيام القديمة كانت خاطئة وقد لا تنفذ إطلاقًا بسبب ترتيب أرقام أيام الأسبوع في Dart.
5. إصلاح إلغاء التذكيرات: كان يتم إلغاء إشعار واحد فقط بينما التطبيق ينشئ عدة إشعارات.
6. منع إنشاء تذكيرات يوم الجمعة، مع دعم السبت–الخميس.
7. تحسين البحث عن الموعد القادم للتذكير ومنع أي حلقة لا نهائية.
8. تحسين التحقق من سعر الساعة والساعات قبل حفظها.
9. تحسين استرداد النسخ الاحتياطية والتحقق من صحة السجلات قبل إدخالها إلى SQLite.
10. استرداد إعدادات المظهر واللون والتذكيرات وأوقات الدوام من النسخة الاحتياطية بدل تجاهل بعضها.
11. إزالة dependency/import غير مستخدم (`share_plus`).
12. تحديث إصدار التطبيق إلى `1.1.0+2`.

## التشغيل

```bash
flutter pub get
flutter run
```

## بناء APK

```bash
flutter build apk --release
```
