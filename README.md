# إضافي | Overtime YER

تطبيق Flutter عربي RTL لحساب ساعات العمل الإضافية بالريال اليمني، يعمل محليًا دون إنترنت.

## الميزات
- إضافة الإضافي بالوقت أو بعدد الساعات.
- جدول دوام افتراضي: السبت–الأربعاء حتى 14:00، الخميس حتى 13:00، الجمعة إجازة.
- سعر الساعة الافتراضي 1500 ريال يمني وقابل للتعديل.
- تقارير يومية وأسبوعية وشهرية ومن تاريخ إلى تاريخ.
- تعديل وحذف السجلات.
- تذكير محلي قابل لتحديد الوقت والأيام.
- Light / Dark / System + ألوان متعددة.
- نسخ احتياطي واسترداد JSON.
- GitHub Actions لبناء APK.

## التشغيل
```bash
flutter pub get
flutter run
```

## بناء APK
```bash
flutter build apk --release
```

يمكن أيضًا تشغيل Workflow من GitHub Actions باسم `Build Android APK`.

> ملاحظة: المشروع يتطلب Flutter SDK مثبتًا محليًا أو بيئة GitHub Actions تحتوي عليه.
